# GUIAS_DE_USUARIO

## Guía rápida ciudadana

### Crear reporte
1. Ir a /reporte/nuevo.
2. Completar ubicación, tipo de incidente, evidencia y descripción.
3. Enviar reporte.
4. Guardar el ID de seguimiento.

### Consultar reportes
1. Ir a /reportes.
2. Buscar por ID o término de ubicación.
3. Abrir resultado para ver detalle en /reportes/:id.

### Usar recorrido de ayuda
1. Clic en botón flotante de ayuda (si está disponible).
2. Seguir los pasos destacados.

## Guía rápida backoffice

### Dashboard
1. Ir a /admin/dashboard.
2. Revisar KPIs y gráficos.
3. Usar accesos directos a módulos.

### Denuncias
1. Ir a /admin/denuncias.
2. Buscar/filtrar.
3. Abrir detalle y gestionar estado.

### Monitoreo
1. Ir a /admin/monitoreo.
2. Abrir detalle de zona.
3. Planificar ruta y responsables.

### Acciones correctivas
1. Ir a /admin/acciones.
2. Filtrar y revisar estados.
3. Actualizar estado según avance.

### Usuarios y sistema
1. /admin/configuracion/usuarios para alta/edición.
2. /admin/configuracion/sistema para ajustes globales.

### Perfil y notificaciones
1. /admin/perfil para editar perfil.
2. /admin/notificaciones para revisar eventos.

## Notas
- Varias operaciones aún simulan backend (mock).
- Los tours auto-start aplican según persistencia local por sección.
